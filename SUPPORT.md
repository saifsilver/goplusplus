# Support policy

Community support is provided through GitHub discussions and issues on a
best-effort basis. This repository does not promise response-time, uptime, or
incident-management SLAs for downstream applications.

Bug reports should include the GoPlusPlus version, Go version, operating system,
minimal reproduction, expected behavior, actual behavior, and sanitized logs.
Questions involving vulnerabilities must follow `SECURITY.md`.

Only GA APIs have semantic-version compatibility commitments. Beta APIs may
change with migration notes in a minor release. Experimental and
development-only APIs may change or be removed without compatibility support.
